GIT HANDLEIDING – MAIN CORRECT PUSHEN

1. Ga naar je projectmap

cd "C:\Users\patri\Documents\pc-tornooien"


2. Controleer de status

git status


3. Zet je wijzigingen klaar

git add .


4. Maak een commit

git commit -m "Korte beschrijving van de wijziging"


5. Haal eerst de nieuwste versie van GitHub op

git fetch origin


6. Werk je lokale main correct bij

git pull --rebase origin main


7. Push naar main

git push origin main
